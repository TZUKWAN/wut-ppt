# 开放式构图知识库（用于选型，不是页面模板）

## 使用原则

1. 本库只用于**张林模板正文内容区**。封面、目录、章节页、红色页标题和底部母版固定，不在本库选型。
2. 先判断页面叙事任务和内容关系，再选宏观构图。
3. 同一套 PPT 中，每个 `Macro composition` 只能使用一次；`custom-*` 也不例外。
4. 本库提供设计起点，不提供可复制的坐标模板。允许 `no-template-match` 和定制构图。
5. 不得仅更换颜色、图标、节点数量或局部形状来制造“新版式”。
6. 渲染语言可以延续，正文宏观构图必须逐页唯一。
7. 每种构图都必须展开到整个正文安全区；不得留下连续空白，不得使用无业务语义的箭头。

## 一、构图候选

| Macro composition ID | 适用任务/关系 | 阅读方式 | 避免情况 |

| `executive-pulse` | 执行摘要、总体判断 | 主结论→证据带 | 等宽 KPI 卡堆叠 |

| `stepped-roadmap` | 阶段升级、能力跃迁 | 左下到右上或逐级 | 阶段无递进 |

| `closing-commitment` | 总结、行动承诺 | 核心判断→行动 | 通用“谢谢”空页 |

## 二、渲染语言（可与不同构图组合）

- `admin-editorial`：细分隔线、边注、强文字层级，适合政策与行政论证。
- `data-journalism`：图表主导、数字锚点、证据标注。
- `engineering-blueprint`：线框、引线、坐标和技术标注。
- `isometric`：立体面、模块装配和空间支撑。
- `swiss-grid`：非对称网格、严格对齐、少容器。
- `dark-tech`：深色底与高对比信息图，适合 AI、平台能力。
- `image-narrative`：真实场景图与标注结合，适合案例与校园场景。

渲染语言可重复形成整套统一感；`Macro composition` 不可重复。

## 三、每页候选决策记录

写 SVG 前先在内部完成：

```text
页面任务：这一页在论证中承担什么？
关系拓扑：内容之间是什么关系？
候选构图：至少两个真正不同的 Macro composition。
选择理由：为什么它最准确，而不是最熟悉？
跨页差异：与此前所有页面的本质区别是什么？
```

如果没有合适候选，使用 `custom-具体构图名`，不要硬套本库。
